KALENDER PERANGKATMU

Pengingat lewat aplikasi kalender

Pindahkan agenda Aturin ke kalender yang biasa kamu pakai.

  1. Unduh file agenda dari tombol di bawah.
  2. Buka file itu dengan aplikasi Kalender atau impor file .ics dari pengaturan kalender.
  3. Aktifkan notifikasi di aplikasi kalender jika diminta.

Setiap perangkat dan aplikasi kalender berbeda. Pengingat hanya berbunyi jika aplikasi mendukung pengingat dari file impor dan izinnya aktif. Ini impor satu kali, bukan sinkronisasi otomatis; ekspor ulang setelah mengubah agenda.
